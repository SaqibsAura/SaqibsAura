## ⚙️ Engineering Principles

1. **Build the system, not the slide deck.**  
   A prototype that only works under ideal conditions is an illusion. True agency is measured by how gracefully software handles API timeouts, unexpected popups, broken pipes, and state drift.

2. **Never ask a neural network to audit its own blast radius.**  
   Probabilistic models generate; deterministic code governs. Security checks, permission barriers, and process-tree kills must be written in unyielding, verifiable code.

3. **Permissions are architecture, not an afterthought.**  
   An agent with unrestricted desktop actuation is a critical hazard. Every action must carry an explicit risk tier and enforce human sign-off before execution.

4. **Multi-sector sovereignty is mandatory.**  
   Relying on a single commercial AI vendor creates brittle software. Systems must dynamically route between providers based on observed latency and sustain basic heuristics offline.

5. **Measure with telemetry, not marketing adjectives.**  
   If an action cannot be verified through an optical diff, an exit code, or a filesystem state change, the system cannot claim completion.
